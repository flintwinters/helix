What if you could read a paused program, save it in Git, and branch its next move?

An active experiment in making execution visible.

01 / THE IDEA

A program you can keep looking at.

A conventional debugger lets you peek into execution. Helix explores what happens when execution itself becomes a document you can inspect, edit, and version.

[01]

Read the whole state

Values, executable forms, and VM state live in an object graph represented as YAML. Suspended frames use object paths, so saved execution can be loaded again.

[02]

Make history tangible

The Python debugger stores snapshots in a per-target Git repository. Step forward, check out an earlier state, or branch an execution to explore another path.

[03]

Zoom into nested VMs

Start and step child virtual machines programmatically. The literal-YAML terminal prototype lets you navigate structured state and follow the active program counter.

02 / A DIFFERENT DEBUGGING LOOP

Keep the moment.
Explore what comes next.

When a run becomes interesting, its YAML state becomes a checkpoint. Inspect the values, preserve the snapshot, and use the debugger’s Git history to revisit it.

This is the motivating direction: reproducible experiments where the state that explains a result remains readable.

03 / WORKING TODAY, BUILDING TOWARD

Small runtime. Ambitious questions.

AVAILABLE NOW

The Helix runtime and debugger

A C++20 runtime with YAML input and output, nested VMs, stepping, breakpoints, structured errors, typed integer assignments, and Git-backed debugging tools.

The Python HUI prototype keeps literal YAML on screen, with semantic navigation, program-counter highlighting, and backward snapshot navigation.

Explore the debugger ↗

IN DEVELOPMENT

Bring this visibility to C

HCC lowers a small C subset into Helix YAML: integer locals, functions, calls, returns, branching, loops, and arithmetic.

Connecting execution back to original C source is the next checkpoint. Microcontroller testing, distributed-system experiments, and a portable C++ terminal interface are directions under exploration.

Read the compiler roadmap ↗

Helix is experimental. HCC is a small compiler slice, and hardware targets are planned work. This is a project to explore and help shape.

04 / TAKE IT FOR A SPIN

Start with one readable program.

You’ll need Python 3.13+, uv, a C++20-capable g++, CMake, and the ryml source tree. The repository’s fixture tests are executable examples of runtime behavior.

BUILD & EXPLORE
git clone https://github.com/flintwinters/helix.git
cd helix
git clone https://github.com/biojppm/rapidyaml.git ryml
uv run python manage.py build
uv run python manage.py cpp-test
uv run python manage.py hui-demo

Follow your curiosity

Launch the terminal demo to see nested execution. Read a fixture to learn a form. Inspect the compiler’s output to see how C becomes a Helix object graph.
